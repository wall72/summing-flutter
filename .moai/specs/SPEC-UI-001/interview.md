# SPEC-UI-001 인터뷰 기록

`/moai plan "모던한 스타일의 크로스플랫폼 퍼즐 게임으로 리팩토링"` 진행 중 오케스트레이터가 받은 사용자 답변입니다. Epic 전체(SPEC-ARCH-001, SPEC-UI-001)에 공통으로 적용됩니다.

## 인터뷰 (4문항)

| # | 질문 주제 | 사용자 답변 | 이 SPEC에 미치는 영향 |
|---|---|---|---|
| 1 | 스타일 방향 | 파스텔 / 소프트 캐주얼 (둥근 모서리, 부드러운 색, 친근한 느낌). 숫자 대비는 WCAG AA 유지, 라이트·다크 모두 지원 | Module 1 (REQ-UI-001 ~ 004), `design.md` §1 ~ §3 |
| 2 | 리팩토링 범위 | UI 전면 개편 + 구조 정리. domain 계층(규칙)은 그대로. 구조 정리(의존 역전)는 SPEC-ARCH-001에서 처리 | 이 SPEC은 UI 전면 개편 담당, REQ-UI-022 |
| 3 | 크로스플랫폼 수준 | 휴대폰·태블릿·데스크톱 폭에 반응하는 웹 (웹이 주 플랫폼). android/ios는 같은 코드로 계속 빌드, 새 플랫폼 러너 없음 | Module 2 (REQ-UI-005 ~ 009), `design.md` §4 |
| 4 | 경험 범위 | 화면 연출만 (배치·매치 애니메이션, 화면 전환, 진행 중일 때 재시작 확인). 새 게임 모드·규칙 변경·온라인 기능 없음. 저장 `schemaVersion`(=1)과 shared_preferences 키 호환 유지 | Module 3, 4 (REQ-UI-010 ~ 019), REQ-UI-022 |

## 확인 질문 (Decision Point 1 이후, 3문항)

| # | 주제 | 결정 | 반영 위치 |
|---|---|---|---|
| 1 | UI 문구 언어 | 영어 유지, l10n 프레임워크 도입 없음 | REQ-UI-023, AC-UI-19 |
| 2 | 폰트 | Nunito Regular + ExtraBold(OFL)를 asset으로 번들, 새 패키지 의존성 없음 | REQ-UI-023, AC-UI-19, `research.md` §5 |
| 3 | 테마 전환 | 시스템 밝기만 따름(`ThemeMode.system`), 앱 내 토글 없음, `AppSettings` JSON 변경 없음 | REQ-UI-002 |

## 추가 확정 사항

- 재시작 확인은 `phase == playing`이면 턴 수와 관계없이 표시합니다. Quit는 저장을 지우지 않으므로 확인하지 않습니다.
- SPEC은 2개로 나누고 SPEC-ARCH-001을 먼저 진행합니다. Tier는 ARCH-001 = M, UI-001 = L.
- 브랜치 작업과 GitHub 이슈 생성은 하지 않습니다.

| 가로 휴대폰(저높이) 배치 (감사 D19) | 플레이 가능한 배치 규칙을 추가한다. 높이 < 480이고 폭 ≥ 480이면 상단 바 없는 두 칸 배치(보드 왼쪽, 사이드 패널 오른쪽)를 쓰고, 568×320에서 보드 ≥ 304, 740×360에서 보드 ≥ 344를 보장한다 | REQ-UI-024, AC-UI-25, `design.md` §4 |
